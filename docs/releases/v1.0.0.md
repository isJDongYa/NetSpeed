## NetSpeed 1.0.0

The first public release of NetSpeed, a compact native macOS menu bar network monitor.

### Download

- **NetSpeed-macOS-universal.zip** — one app for **Apple Silicon and Intel**, requiring **macOS 13 or later**.
- **SHA256SUMS.txt** — SHA-256 checksum for the app archive.

The app archive and checksum are attached automatically after GitHub Actions builds and checks the tagged source. Source-code archives alone are not the app download.

### Features

- Real-time download and upload speeds in a two-line menu bar display.
- Width that follows the longer line, including when digits and units change.
- Automatic primary-interface selection and manual network-interface controls.
- Byte/bit units, optional launch at login, and 64-bit traffic counters.
- Native AppKit interface, no third-party dependencies, and no outgoing network requests.

### Install

Unzip the download, move **NetSpeed.app** to `~/Applications` or `/Applications`, and open it. The menus currently use Simplified Chinese.

The app is **ad-hoc signed and not notarized**. macOS may require first-launch approval in **System Settings → Privacy & Security**. The source is available under the **MIT License**.
